# RADIVEX AI
### Radiology Vision Intelligence

Advancing Medical Image Analysis Through AI.

RADIVEX AI is an AI-based research project focused on chest X-ray image analysis using Deep Learning and Vision Transformer architectures.

## Features
- Chest X-ray image preprocessing
- Dataset preparation and validation
- Multi-label classification
- Vision Transformer experiments
- Model training and evaluation
- Prediction and inference

## Technology Stack
- Python
- PyTorch
- OpenCV
- NumPy
- Pandas
- Scikit-learn
- Hugging Face
- Git and GitHub
